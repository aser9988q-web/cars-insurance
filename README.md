# تأميني - Cars Insurance

منصة مقارنة أسعار تأمين المركبات والطبي والسفر اونلاين

## الميزات

- 🚗 مقارنة أسعار تأمين المركبات
- 🏥 خدمات التأمين الطبي
- ✈️ تأمين السفر
- 💰 أسعار تنافسية
- 📱 واجهة سهلة الاستخدام
